 Event Management Website

 Project Overview
This is a simple Event Management website developed using HTML5 and CSS3. The project is designed to display upcoming events, event details, gallery section, and contact information in a structured and user-friendly format.

The main goal of this project is to practice frontend web development and understand how to build real-world static websites using HTML and basic CSS.


 Features
-  Upcoming Events section with event descriptions  
-  Event Gallery section  
-  Fashion Store event display  
-  Embedded YouTube video for engagement  
-  Contact section with phone, email, and location details  
-  Simple and clean UI design  


 Technologies Used
- HTML5  
- CSS3  



 Project Structure
- Home Page (Event Details)  
- Gallery Section  
- Contact Section  
- Embedded Media (YouTube iframe)  


 Objective
The objective of this project is to learn how to structure web pages, organize content, and apply basic styling to create a simple and interactive website.


 What I Learned
- Structuring web pages using HTML  
- Using headings, paragraphs, lists, and tables  
- Embedding videos using iframe  
- Designing simple layouts using CSS  
- Building a real-world static website  



 How to Run
1. Clone or download the repository  
2. Open `index.html` in any browser  
3. Explore the website
